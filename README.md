# Board-Open-PLC-with-Raspberry-Pico-2

Diseño de placa para el entorno Open PLC, contiene 8 entradas digitales, con 4 pulsadores auxiliares de prueba para las primeras entradas, entrada analogica, las 8 salidas digitales al modulo de reles, dos salidas analogicas con amplificacion de señal mediante operaciónal y salida I2C.
